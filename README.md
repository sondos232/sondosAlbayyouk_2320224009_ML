# House Prices - Assignment 1 Sondos AL-bayyouk

This project is for the first Machine Learning assignment.
The goal is to preprocess the House Prices dataset and prepare it for modeling.

## What I did

* Loaded the training and testing data (train & test)
* Cleaned the data and handled missing values
* Removed some outliers
* Applied log transformation on SalePrice
* Performed basic exploratory data analysis (EDA)
* Created a new feature (TotalSF) and encoded categorical variables (these steps are commented out because they are already applied in the preprocessing pipeline and should not be executed twice)

## Files

* notebook.ipynb → contains all the work
* data/ → contains train.csv and test.csv

## How to run

Clone or download the repository
Place the data folder (containing train.csv and test.csv) in the project directory
Open the notebook using Jupyter Notebook (Anaconda) or Google Colab
Run all cells

## Note

I developed this notebook using Google Colab, and it runs without errors in that environment so
it may require minor adjustments if run locally.
